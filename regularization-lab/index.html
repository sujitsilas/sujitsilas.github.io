Too good to be true?

A model is a rule with numbers you can tune

These dots are 12 measurements of an enzyme's activity at different temperatures. A model is a rule that predicts activity from temperature. The simplest rule is a straight line. Its two numbers, β0 and β1, are the model's coefficients. Fitting a model means choosing the coefficients that make the misses (the thin vertical lines) as small as possible.

Even the best straight line can't follow the hump. A model this simple underfits: it misses the real pattern.

Give it more coefficients and it starts memorizing

To let the line bend, we add more terms: ŷ = β0 + β1x + β2x² + … + βdxd, where x is temperature rescaled to run from −1 to 1. This is still linear regression: x², x³ and so on are just extra columns of data, each with its own coefficient. The real test is the hollow circles: new samples the model never saw while fitting.

The fix: make big coefficients cost something

The degree-10 model above fits the training samples perfectly by using enormous coefficients, thousands in size, that cancel each other out. Regularization changes what "best" means. The model no longer just minimizes its misses; it also pays a penalty for big coefficients. It picks the coefficients that make this total as small as possible:

Σ (yi − ŷi)²Fit: how badly the model misses the training data + λLambda: the price of each unit of penalty. You choose it. × penaltyHow big the coefficients are, measured one of two ways

L1 penalty (LASSO)

|β1| + |β2| + … + |βd|

Adds up the sizes. Every coefficient pays the same rate however small it is, so small ones get pushed all the way to exactly 0.

L2 penalty (ridge)

β1² + β2² + … + βd²

Adds up the squares. A tiny coefficient costs almost nothing (0.1² = 0.01), so everything shrinks, but nothing reaches exactly 0.

L1 vs. L2: same idea, different behavior

A drug-response study measured 12 genes (G1 to G12) in 24 patients. The model is the same kind of linear regression: response = β0 + β1·G1 + β2·G2 + … + β12·G12. Need a hint?

Think about price. Under L1, shrinking a coefficient from 0.1 to 0 saves 0.1 × λ, the same rate as anywhere else, so it's worth finishing the job. Under L2, it saves only 0.01 × λ (that's 0.1² − 0²), which is almost nothing.

Choosing λ: test on patients the model hasn't seen

Too little penalty overfits; too much shrinks everything to zero, and then the model just predicts the average. To find the middle, use cross-validation: split the 24 patients into 5 groups, fit the model on 4 groups, measure its miss on the 5th, and repeat until every group has had a turn as the test group.

What to remember

Overfitting
Training error is low but error on new data is much higher. The model memorized noise instead of learning the pattern.
Regularization
Minimize Σ (yi − ŷi)² + λ × penalty. The penalty keeps coefficients small, so the model can't chase noise.
L1 (LASSO)
Penalty = sum of |β|. Pushes some coefficients to exactly 0, so it also picks which features to keep.
L2 (ridge)
Penalty = sum of β². Shrinks every coefficient smoothly toward 0, but keeps them all.
Choosing λ
Use cross-validation: pick the λ with the lowest error on held-out data, or a slightly larger λ that gives a simpler model with nearly the same error.
